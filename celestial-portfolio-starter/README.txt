CELESTIAL PORTFOLIO STARTER
============================

FILES
- index.html        Homepage
- astral-fates.html Astral Fates project page with clickable character profiles
- about.html        About page starter
- styles.css        Shared visual design and responsive layout
- script.js         Mobile navigation, current year, character switching

FIRST CUSTOMIZATIONS
1. Open the folder in Visual Studio Code.
2. Search all files for:
   - YOUR NAME
   - YOUR ARTIST NAME
   - YOUR_EMAIL@example.com
   Replace these with your real details.
3. In index.html, update the introduction and music/project descriptions.
4. In astral-fates.html, replace the trailer/dialogue placeholders with your own video embeds.
5. In script.js, replace the sample character descriptions with your approved bios.
6. Replace the artwork placeholders with your own images. Keep image files in an "images" folder and use paths such as images/nari.png.
7. Open index.html in a browser to preview the site.

PUBLISHING WITH GITHUB PAGES
1. Create a GitHub account and a new PUBLIC repository.
2. Upload all files from this folder (keep the filenames and folder structure).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and the root folder, then Save.
6. Wait for GitHub Pages to publish your site. The URL will appear in the Pages settings.

PRIVACY
A free GitHub Pages site uses a public repository. Do not upload private information,
unreleased material you are not ready to make public, or credentials/secrets.

NOTES
- The character portraits and videos are placeholders; this starter does not include your original assets.
- The character profiles are intentionally sample copy. Replace it with your actual character bios.
- Google Fonts are loaded online; the site falls back to system fonts if unavailable.
- This is a static website. A contact email link is included; it is not a server-backed contact form.
